# Example projects

These files are complete SHC Eco Simulator layouts. Download any `.json` file and open it with **File > Open**. The application recalculates paths and economy results after loading.

| File | Format | Purpose |
| --- | ---: | --- |
| `2k8pt_3green_CN_Manuel.json` | 2 | Mixed three-farm bread and weapon economy with walls and population settings |
| `2k8pt_3green_eco_squad_rustam.json` | 2 | Alternative mixed three-farm layout |
| `2k8pt_3green_optimized.json` | 2 | Optimized mixed layout without temporary walls |
| `3k5pt_bread_eco.json` | 2 | Large bread economy with 12 farms, 8 Mills, and 60 Bakeries |
| `bread_eco_sword.json` | 2 | Large bread layout with additional Armourers |
| `eco.json` | 1 | Legacy large bread layout used to test version 1 compatibility |
| `test_bakers.json` | 1 | Small legacy Bakery-focused test layout |

Project JSON stores the editable economy, not calculated output. This keeps examples portable across calculation improvements: open the file and press **Recalculate** whenever you want fresh results from the current application version.

The examples are ordinary project files. You can modify one and use **Save As** to keep your own variant.
